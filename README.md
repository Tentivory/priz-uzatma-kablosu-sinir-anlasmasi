# Priz Uzatma Kablosu Sınır Anlaşması

Bu depo, evdeki çoklu prizin uluslararası hukuk öznesi olduğu varsayımıyla kurulmuştur. Varsayım yanlıştır. Yazılım yine de çalışır.

Telefon şarjı sol deliği ister. Lamba sağ deliği vatan ilan eder. Süpürge ortayı işgal eder ve bunu geçici üs diye raporlar. Uzatma kablosu ise tarafsız bölge olduğunu söylerken herkesin ayağına dolanır. Bu, diplomasidir.

## Ne işe yarar

Hiçbir şeye. Ama resmi biçimde hiçbir şeye.

`sinir_anlasmasi.py` cihazları masaya oturtur, watt kavgasını puanlar, bir delik dağıtır, antlaşma metni basar ve kaybeden fişe tazminat olarak bir adet "sonra takarsın" vaadi verir. Vaadin hukuki bağlayıcılığı, çay tabağının altındaki fiş kadarıdır.

## Çalıştırma

```bash
python3 sinir_anlasmasi.py
python3 sinir_anlasmasi.py --cihazlar "sac kurutma,ekmek kizartma,telefon,lamba"
```

Python 3 yeter. Bağımlılık yoktur. Priz de yoktur. Sorumluluk reddi: gerçek bir çoklu prize bu programı takmayın, o zaten dolu.
